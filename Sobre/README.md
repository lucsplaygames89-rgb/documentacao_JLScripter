# Sobre o JLScript

JLScript é uma linguagem de programação criada por **Lucas Aguiel**, com foco em simplicidade, legibilidade, produtividade e facilidade de aprendizado.

O projeto surgiu em 2026 a partir da ideia de desenvolver uma linguagem que fosse simples de escrever, fácil de entender e, ao mesmo tempo, capaz de evoluir para projetos maiores.

Desde o início, o JLScript foi pensado para permitir que pessoas com diferentes níveis de experiência pudessem aprender programação de forma mais natural, utilizando uma sintaxe clara e familiar.

---

## Origem

A ideia do JLScript nasceu a partir do interesse de Lucas Aguiel por programação e da experiência com outras linguagens.

Durante o aprendizado e desenvolvimento de projetos, surgiu a vontade de criar uma linguagem própria que tivesse uma sintaxe simples, direta e fácil de compreender.

O objetivo inicial era reduzir algumas dificuldades encontradas ao programar, principalmente em situações onde uma sintaxe mais simples poderia tornar o código mais legível.

A proposta começou pequena, com estruturas básicas como variáveis, condições, funções e repetições.

Com o tempo, o projeto cresceu e passou a incluir componentes próprios responsáveis por interpretar, executar e organizar programas escritos em JLScript.

---

## Origem do nome

O nome **JLScript** possui uma origem pessoal.

As letras representam:

- **J** — Joicy Costa
- **L** — Lucas Aguiel
- **S** — Script

O nome nasceu da combinação entre Joicy Costa, Lucas Aguiel e a ideia de uma linguagem de scripts.

Dessa forma, o nome JLScript passou a representar tanto a origem pessoal do projeto quanto a identidade da linguagem.

---

## O criador

JLScript foi criado por **Lucas Aguiel**.

O projeto surgiu inicialmente como uma experiência pessoal de aprendizado e desenvolvimento.

Ao estudar programação, surgiu o interesse por entender como linguagens funcionavam internamente e como seria possível criar uma linguagem própria.

A partir disso, Lucas começou a desenvolver estruturas básicas da linguagem.

O projeto evoluiu gradualmente.

O que inicialmente era apenas uma ideia de sintaxe passou a contar com diferentes componentes responsáveis pelo funcionamento da linguagem.

Entre eles estão sistemas responsáveis por:

- interpretar código;
- analisar a sintaxe;
- executar instruções;
- trabalhar com bibliotecas;
- gerenciar módulos;
- executar comandos pelo terminal;
- construir aplicações;
- organizar ferramentas do ecossistema.

Com essa evolução, o JLScript deixou de ser apenas uma experiência de sintaxe e passou a se tornar um projeto de linguagem de programação completo.
