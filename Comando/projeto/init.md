# `jls init`

Inicializa um novo projeto básico.

```powershell
jls init
jls init <nome>
```

Sem nome, usa o nome da pasta atual como nome solicitado ao criador de projeto. A implementação atual reutiliza a mesma rotina de criação de `jls new`, portanto ela cria uma nova pasta de projeto em vez de preencher silenciosamente a pasta atual.
