# A origem do JLScript 🇧🇷

## Uma linguagem brasileira

O **JLScript** é uma linguagem de programação brasileira, criada em **2026** por **Lucas Aguiel Dos Santos De Oliveira**, um programador baiano, durante o desenvolvimento do projeto em **Águas Lindas de Goiás, Goiás, Brasil**.

Desde sua origem, o JLScript não foi pensado apenas como um experimento técnico.

A ideia era criar algo que fosse **divertido de programar**, mas que ao mesmo tempo pudesse se tornar uma linguagem séria e capaz de construir projetos reais.

O projeto nasceu com uma combinação de ideias:

> **A facilidade do Python, a lógica e familiaridade do JavaScript e uma identidade própria brasileira.**

O objetivo não era criar um "Python brasileiro" ou simplesmente modificar JavaScript.

Era estudar o que tornava essas linguagens agradáveis ou fáceis de utilizar e, a partir disso, construir algo novo.

---

## Por que criar outra linguagem?

Existem centenas de linguagens de programação.

Então por que criar mais uma?

Porque programar também pode ser experimentar.

O JLScript nasceu da vontade de construir uma linguagem que não fosse apenas funcional, mas também **agradável de escrever e fácil de compreender**.

Algo em que um iniciante pudesse olhar para:

```jls id="cekknt"
va nome = "Lucas"

se (nome == "Lucas") {
    mostrar("Olá, Lucas!")
}
```

e conseguir ter uma ideia do que está acontecendo mesmo sem conhecer profundamente a linguagem.

Ao mesmo tempo, simplicidade não deveria significar criar uma linguagem limitada.

A proposta passou a ser:

**começar fácil e permitir chegar longe.**

---

## Fácil como Python

Uma das inspirações do JLScript é a simplicidade encontrada no Python.

Não necessariamente sua sintaxe exata, mas sua filosofia de permitir que tarefas simples continuem simples.

No JLScript, escrever um primeiro programa não deveria exigir conhecer dezenas de conceitos:

```jls id="0gnr37"
mostrar("Olá, mundo!")
```

Uma variável também deveria continuar simples:

```jls id="iglg8v"
va linguagem = "JLScript"
```

O programador aprende primeiro **o que está fazendo**.

A complexidade aparece conforme ele realmente precisa dela.

---

## Lógico e familiar como JavaScript

O JavaScript teve uma influência diferente.

Sua estrutura com blocos, operadores, condições e funções ajudou a formar parte da lógica inicial do JLScript.

Por isso, algumas estruturas podem parecer familiares:

```jls id="a4f9wc"
se (idade >= 18) {
    mostrar("Maior de idade")
} senao {
    mostrar("Menor de idade")
}
```

Mas familiaridade não significa copiar todas as decisões da linguagem.

Quando alguma coisa poderia ser simplificada, o JLScript poderia seguir outro caminho.

Um exemplo está no `switch`.

```jls id="86zx9q"
switch (opcao) {
    case 1 {
        mostrar("Iniciar")
    }

    case 2 {
        mostrar("Configurações")
    }

    default {
        mostrar("Opção inválida")
    }
}
```

Não existe necessidade de colocar um `break` depois de cada caso.

O fechamento do próprio bloco:

```jls id="y6ajh6"
}
```

já representa seu encerramento.

Se a linguagem consegue entender onde o bloco termina, não existe motivo para obrigar o programador a repetir essa informação.

Essa maneira de pensar começou a formar a identidade do JLScript.

# Feito no Brasil

O JLScript é originalmente brasileiro.

Ele não foi criado primeiro no exterior para depois receber tradução para português.

O português faz parte da origem da linguagem.

```jls id="azf5qd"
va pais = "Brasil"

se (pais == "Brasil") {
    mostrar("JLScript nasceu aqui.")
}
```

O projeto nasceu e começou seu desenvolvimento em **Águas Lindas de Goiás**, no estado de Goiás, por um desenvolvedor originalmente da **Bahia**.

Isso também influenciou uma das características mais importantes da linguagem: permitir que conceitos de programação possam ser expressos naturalmente em português.

O português não precisa ser tratado como uma tradução secundária.

Ele pode fazer parte da própria linguagem.

---

# Uma linguagem para ser divertida e séria

Existe uma ideia central por trás do JLScript:

> **Uma linguagem não precisa ser complicada para ser levada a sério.**

O JLScript busca tornar a experiência de programar divertida para quem está aprendendo ou simplesmente construindo alguma ideia, sem abandonar recursos necessários para projetos maiores.

A intenção é permitir que alguém comece com:

```jls id="15joxd"
mostrar("Olá!")
```

e, conforme aprende, possa avançar para aplicações, APIs, bibliotecas e outros tipos de projetos sem precisar abandonar a linguagem.

Por isso, o JLScript tenta ocupar dois espaços ao mesmo tempo:

**ser simples o suficiente para começar e completa o suficiente para continuar.**

---

# Identidade própria

Com o crescimento do projeto, o JLScript começou a deixar de ser apenas uma linguagem criada durante o aprendizado de programação.

Ele começou a ganhar identidade própria.

Uma linguagem brasileira.

Criada por um programador brasileiro.

Desenvolvida inicialmente em Águas Lindas de Goiás.

Com suporte ao português desde sua concepção.

Inspirada por ideias encontradas em outras linguagens, mas construída com suas próprias decisões.

O JLScript nasceu de uma pergunta simples:

> **"Como seria uma linguagem feita do jeito que eu gostaria de programar?"**

Desde 2026, o projeto continua tentando responder essa pergunta, recurso por recurso e linha por linha.
